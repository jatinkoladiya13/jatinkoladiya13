## ⭐ Featured Project

### 💇 [Salon Management Platform](https://github.com/jatinkoladiya13/salon_management)
A **multi-tenant SaaS backend** where each salon runs in its own PostgreSQL schema.

- Schema-per-tenant isolation with `django-tenants`; JWTs are tied to the tenant and checked against the request host
- Role-based access for platform admin, salon admin, staff, and customers
- Appointments, time slots, services, product catalog, inventory, carts, and invoices
- Stripe subscriptions and checkout via webhooks (dj-stripe), plus Razorpay support
- Celery + Celery Beat for reminders and recurring slots; Django Channels for real-time updates
- Elasticsearch search, two-factor authentication (OTP), and Docker + Nginx setup

`Django 5` `DRF` `PostgreSQL` `Celery` `Redis` `Channels` `Stripe` `Elasticsearch` `Docker`
